Admin Lotes

Gestión de proyectos inmobiliarios multiempresa, con app de campo para asesores.

Qué incluye

  • Seguimiento de lotes para asesores de venta en campo

  • Arquitectura por capas con SOLID e inyección de dependencias

Stack
